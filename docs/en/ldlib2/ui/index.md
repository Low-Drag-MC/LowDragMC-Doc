# Introduction
<VersionBadge version="2.1.0" label="Since" icon="tag" />

LDLib2 provides powerful UI library based on the [`Taffy`](https://taffylayout.com/) layout engine. 
If you are struggling with GUI development, LDLib2 is definitely one of your best choice. Compared with the LDLib, LDLib2 has undergone a complete refactoring:

* modern UI layout system
* modern UI event system
* CSS-like stylesheet system
* data binding + rpc event
* massive plug-and-play components
* xml support + in-game UI visual editor
* xei / kjs supports
* completed document and usage examples

::: tip Declarative UI with Compose
<VersionBadge version="2.2.44" label="Since" icon="tag" />

The optional [`ldlib2-compose`](./compose/index.md) module builds the same element tree from Kotlin `@Composable` functions, so the UI follows your state without manual rebuilds. It is a separate mod and dependency.
:::
